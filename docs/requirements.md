# 需求规格说明 — ClipHistory

> 版本：v1.0 | 日期：2026-06-02

---

## 1. 项目概述

**ClipHistory** 是一款 Windows 桌面应用，自动记录用户复制的文字和图片，提供历史查看、搜索、置顶、删除功能，支持设定存储时长自动清理。

---

## 2. 目标用户

- 日常办公人员：经常需要找回之前复制的内容
- 内容创作者：需要管理大量复制素材
- 普通 Windows 用户：需要简单实用的粘贴板增强工具

---

## 3. 功能需求

### 3.1 粘贴板监听（FR-01）

| 项目 | 说明 |
|------|------|
| **触发方式** | 自动监听系统粘贴板变化，无需用户操作 |
| **支持格式** | 纯文本（text/plain）、图片（image/png, image/jpeg, image/bmp） |
| **去重逻辑** | 连续两次复制相同内容时，不重复记录（更新原记录时间） |
| **运行条件** | 应用启动后持续监听，包括后台运行时 |

### 3.2 历史记录展示（FR-02）

| 项目 | 说明 |
|------|------|
| **展示方式** | 卡片列表，每条记录一张卡片 |
| **排序规则** | 按创建时间降序（最新在最上面），置顶内容优先 |
| **卡片内容** | 文字：显示内容摘要（前 100 字）；图片：显示缩略图 |
| **时间显示** | 显示复制时间，格式为 "YYYY-MM-DD HH:mm:ss" |

### 3.3 再次粘贴（FR-03）

| 项目 | 说明 |
|------|------|
| **操作方式** | 点击任意历史记录卡片 |
| **行为** | 将该条内容重新写入系统粘贴板，用户可在任意应用中 Ctrl+V 粘贴 |
| **反馈** | 显示"已复制"提示 |

### 3.4 搜索功能（FR-04）

| 项目 | 说明 |
|------|------|
| **搜索范围** | 仅搜索文字类型记录的内容 |
| **匹配方式** | 模糊匹配（LIKE %keyword%） |
| **实时过滤** | 输入关键词后实时过滤列表 |
| **清除搜索** | 提供清除按钮，一键恢复完整列表 |

### 3.5 置顶功能（FR-05）

| 项目 | 说明 |
|------|------|
| **操作方式** | 每条卡片上有置顶按钮（📌图标） |
| **行为** | 点击后该记录固定到列表最顶部 |
| **取消置顶** | 再次点击取消置顶，恢复按时间排序 |
| **影响** | 置顶的内容不受自动清理规则影响 |

### 3.6 删除功能（FR-06）

| 项目 | 说明 |
|------|------|
| **单条删除** | 每条卡片上有删除按钮（🗑️图标），点击后确认删除 |
| **确认机制** | 弹出确认提示，防止误删 |
| **图片清理** | 删除图片记录时同时删除对应图片文件 |

### 3.7 存储时长设置（FR-07）

| 项目 | 说明 |
|------|------|
| **可选天数** | 1天 / 3天 / 5天 |
| **默认值** | 3天 |
| **清理时机** | 每次应用启动时执行一次清理检查 |
| **清理规则** | 删除创建时间超过设定天数且未被置顶的记录 |

### 3.8 系统托盘（FR-08）

| 项目 | 说明 |
|------|------|
| **托盘图标** | 应用运行时始终显示在任务栏右下角 |
| **右键菜单** | 显示主窗口 / 退出应用 |
| **关闭行为** | 点击窗口关闭按钮 → 隐藏到托盘，不退出 |
| **真正退出** | 通过托盘右键菜单"退出"彻底关闭 |

### 3.9 全局快捷键（FR-09）

| 项目 | 说明 |
|------|------|
| **默认快捷键** | Ctrl+Shift+V |
| **功能** | 在任意应用中按下 → 显示/隐藏主窗口 |
| **冲突处理** | 如果快捷键被其他应用占用，提示用户 |

### 3.10 开机自启（FR-10）

| 项目 | 说明 |
|------|------|
| **默认状态** | 开启 |
| **实现方式** | 注册到 Windows 系统启动项 |
| **可选关闭** | 在设置页面中可关闭开机自启 |

## 4. 非功能需求

### 4.1 性能

| 指标 | 要求 |
|------|------|
| 粘贴板响应延迟 | < 200ms |
| 1000条记录列表渲染 | < 1秒 |
| 搜索过滤响应 | < 300ms |

### 4.2 资源占用

| 指标 | 要求 |
|------|------|
| 内存占用（空闲） | < 100MB |
| 磁盘占用（数据库+图片） | 由存储时长自动控制 |

### 4.3 兼容性

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / Windows 11 |
| 架构 | x64 |

---

## 5. 约束与限制

- 不记录来自密码管理器（如 1Password、Bitwarden）的内容 — **用户要求：全部记录，不做过滤**
- 图片大小限制：单张不超过 50MB
- 不支持富文本格式（HTML/RTF），仅纯文本

---

## 6. 项目素材（2026-10-26）

- 支持新建、重命名、删除项目，每个项目独立保存常用素材并显示素材数量。
- 支持文字（直接输入正文、不设置或显示标题、保留原始换行与空格）、图片、视频和任意文件。
- 可手动添加/编辑文字、多选导入文件，或将已有剪贴板历史保存到项目。
- 历史记录和项目素材支持移动或复制到目标项目（也可现场新建）。复制保留来源；移动在目标保存成功后移除来源。
- 项目间移动保留素材 ID 和已有文件副本，项目间复制文件创建独立副本；目标不能为素材当前所在项目。失败时原内容保留。
- 文件导入时保存独立副本，保留原文件名；原文件移动或历史清理不影响已保存素材。
- 项目素材永久保存，仅手动删除；历史保留天数、条数限制和“清空全部历史”均不影响项目。
- 支持项目内按正文和文件名搜索与类型筛选，提供文件定位和删除确认。单击素材卡片或聚焦卡片按 Enter/空格即可复制，不提供单独的复制按钮；编辑、移动、定位与删除不触发复制。
- 移除独立“提示词”分类；已有提示词启动时自动迁移至独立「常用文本」项目，原文与时间保留、迁移不重复、失败时来源保留；同名项目不混入旧提示词。
- 图片复制为位图，视频和其他文件复制为 Windows 文件剪贴板，可在支持对应内容的应用粘贴。
