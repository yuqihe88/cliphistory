## 技术债务记录

| 项 | 说明 | 影响 |
|----|------|------|
| sql.js 替代 better-sqlite3 | Windows 无 MSVC 编译器，改用 WASM 版 | 每次写入需手动 saveToDisk()，略有性能开销 |
| 粘贴板轮询 | 500ms setInterval 轮询 | 非事件驱动，极端情况可能丢失快速复制 |
| 应用图标 | assets/icon.png 已生成（256×256 蓝色圆形） | 打包时图标嵌入需 winCodeSign 工具（需 GitHub 访问） |
