## 🚧 遇到的问题 & 解决方案

| 问题 | 解决 |
|------|------|
| better-sqlite3 需要 MSVC 编译 | 改用 sql.js（WASM 版 SQLite），功能等价无需原生编译 |
| node_modules/electron 被系统锁定无法删除 | 先清空目录内容（锁释放），再整体替换 |
| clipboard.ts ↔ index.ts 循环依赖 | 改为回调模式：`setOnNewClip(callback)` |
| `nativeImage` 作为类型使用 TS 报错 | 导入 `NativeImage` 类型（Electron 导出名） |
| `app.isQuitting` 不在 Electron 类型中 | 使用 `(app as any).isQuitting` 绕过 |
| electron-auto-launch@^2.0.0 版本不存在 | 改为 ^5.0.7（当前实际版本） |

## 💡 技术备注

- **sql.js 数据库路径**：`%APPDATA%/cliphistory/cliphistory.db`
- **图片存储路径**：`%APPDATA%/cliphistory/images/`
- **数据库持久化**：每次写操作后调用 `saveToDisk()` 将内存数据库导出到文件
- **WASM 加载**：`initDatabase()` 是异步的，主进程 `app.on('ready')` 用了 `async`
- **开发模式判断**：检查 `VITE_DEV_SERVER_URL` 环境变量；生产模式加载 `dist/renderer/index.html`
- **单实例锁**：`app.requestSingleInstanceLock()` 防止多开
