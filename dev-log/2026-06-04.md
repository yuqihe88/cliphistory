## ✅ 今日完成

### 🔴 会话一：验证应用首次运行成功

**阻塞问题排查**：
| 问题 | 根因 | 解决 |
|------|------|------|
| `require('electron')` 返回字符串而非 API | Shell 环境 `ELECTRON_RUN_AS_NODE=1`，使 Electron 以纯 Node.js 模式运行 | `unset ELECTRON_RUN_AS_NODE` |
| Electron 二进制缺失 | 官方 GitHub 源下载超时（国内网络） | npmmirror 镜像安装（27.3.11） |
| Vite 端口不一致 | 硬编码 5173，但 Vite 被占用时自动换端口 | vite.config.ts 固定 5173 + strictPort；主进程读 `VITE_DEV_SERVER_URL` |
| React 页面空白 | CSP 阻止 Vite HMR 内联脚本 | 添加 `'unsafe-inline'` + `ws://localhost:*` |
| `window.clipHistory` undefined | preload 沙箱无法 `require("../shared/types")` | 完全重写 preload.ts，内联 12 个 IPC 常量 |

**修改文件**：
- `src/main/index.ts` — 开发 URL 从环境变量读取，fallback 到 `localhost:5173`
- `src/main/preload.ts` — 完全重写，内联所有 IPC 常量
- `src/main/clipboard.ts` — 添加调试日志
- `src/renderer/index.html` — CSP 修复
- `src/renderer/App.tsx` — 添加调试日志
- `package.json` — dev:main 脚本清除 `ELECTRON_RUN_AS_NODE`
- `vite.config.ts` — 添加 `server.port: 5173, strictPort: true`

**验证结果**：
- ✅ 主进程启动（数据库/IPC/窗口/托盘/快捷键/粘贴板监听全部初始化）
- ✅ 全局快捷键 Ctrl+Shift+V 注册成功
- ✅ 粘贴板监听写入数据库（10+ 条记录确认）
- ✅ React 页面渲染正常
