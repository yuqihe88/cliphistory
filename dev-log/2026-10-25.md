# 开发日志 — 2026-10-25

## ✅ 今日完成

### 1. 隐私保护：暂停记录 + 排除应用

- **暂停记录**：设置 `paused`；轮询采集直接短路，主页顶部显示红色提示横幅；入口两处——设置页开关（红色滑块）、「操作」菜单「暂停记录 / ✓ 恢复记录」
- **排除应用**：设置 `excludedApps`（进程名数组，JSON 存储于 app_settings）；UI 为多行文本框（每行一个进程名，如 Bitwarden、keepassxc，匹配时忽略大小写和 .exe 后缀），有改动才显示「保存名单」按钮
- **归属进程追踪**（新模块 `src/main/clipboard-owner.ts`）：Electron 无"剪贴板内容来自哪个应用"的 API，方案为常驻 PowerShell 辅助进程——每 250ms 用 user32 `GetClipboardOwner` + `GetWindowThreadProcessId` + `Get-Process` 读取归属进程名，变化时输出一行，主进程 readline 缓存最新值；名单非空才启动、清空即停止（`syncOwnerTracker`）
- **过滤点**：文本/位图/文件三条采集路径在哈希去重之后、入库之前检查归属，命中名单则丢弃（不动 last*Hash，归属更换后可正常采集）
- **验证**：暂停/恢复切换 ✅；名单非空启动追踪、清空停止（日志确认）✅

### 2. 存储控制：条数上限 + 图片压缩

- **条数上限**：设置 `maxRecords`（100/500/1000/不限，默认 500）；`enforceRecordCap()` 在每次入库与上限变更后执行——删除最旧的未置顶记录（置顶受保护），应用自管理的图片文件同步清理
- **图片压缩**：位图捕获改为「超过 1920px 先等比缩小 → JPEG 质量 80」（Electron nativeImage 无 WebP 编码器）；截图类图片体积约降一个数量级；文件扩展名 .jpg，clipimg 协议 MIME 已含
- **验证**：maxRecords 设为 5 → 日志 `[Cap] 超出上限 5 条，清理 67 条最旧记录`，恢复 500 ✅

### 3. 重新打包正式版
